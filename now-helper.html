넥슨 NOW 전체 저장 버튼

넥슨 NOW 화면에서 버튼 한 번만 누르면 해독기·강화·개조·상자·파츠·각성 메뉴를 차례로 열어서 모든 확률표를 파일 하나로 저장해요.

1

즐겨찾기 막대 켜기

크롬에서 Ctrl + Shift + B를 누르면 주소창 아래에 즐겨찾기 막대가 나타나요. (이미 보이면 넘어가세요)

2

아래 노란 버튼을 즐겨찾기 막대로 끌어다 놓기

버튼을 누르지 말고, 마우스로 잡아서 즐겨찾기 막대 위에 놓으세요. 처음 한 번만 하면 돼요.

⬇ 넥슨NOW 전체 저장
끌어다 놓기가 안 되면: → 즐겨찾기 막대에서 마우스 오른쪽 → 페이지 추가 → 이름은 "넥슨NOW 전체 저장", URL 칸에 붙여넣기(Ctrl+V) → 저장
3

넥슨 NOW에서 버튼 누르기

넥슨 NOW 카스온라인 확률 페이지 ↗를 열고, 즐겨찾기 막대의 넥슨NOW 전체 저장을 누르세요. 오른쪽 아래에 진행 상황이 나오고 메뉴가 자동으로 하나씩 바뀌어요. 메뉴 34개 기준 1분쯤 걸리니 끝날 때까지 그대로 두세요.

4

내려받은 파일 올리기

끝나면 nexon-now-all_날짜.html 파일 하나가 다운로드돼요. 이 파일을 GitHub nexon-now 폴더 ↗에 끌어다 놓고 Commit changes를 누르면 1~2분 뒤 사이트에 전부 반영돼요.

· 버튼은 내 브라우저에서 메뉴를 사람이 누르는 속도로 차례로 눌러 보이는 표를 모으기만 해요. 다른 사이트로 아무것도 보내지 않아요.
· 패치로 확률이 바뀌었을 때(보통 1년에 4번 정도) 다시 한 번 누르고 올리면 돼요.
· 저장소 업로드는 저장소 주인만 할 수 있어요.
